# LIR9

LIR9 is a Persian-first English learning platform designed to guide learners through CEFR levels A1 to C1.

## Current milestone

The first frontend foundation is being built with React, TypeScript, and Vite. The current scope is a responsive Persian landing page and initial product identity.

## Product vision

- Structured English lessons from A1 to C1
- Grammar, vocabulary, listening, reading, speaking, and writing practice
- Exercises, assessments, and learner progress tracking
- An AI learning assistant with controlled usage
- Responsive web experience, with PWA support planned

## Development status

This is an early frontend milestone. Authentication, backend services, database, reviewed course content, assessments, AI integration, and payments are not implemented yet.

## Local development

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```

## Design direction

Black and gold visual identity with a Persian right-to-left interface.
